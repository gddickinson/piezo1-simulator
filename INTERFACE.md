# INTERFACE.md — navigation map

The top-level map of this project. **Read this before opening any source file.**
Status markers: ✅ implemented · 🚧 in progress · 📋 planned.

---

## Dependency direction

```
io ──▶ core ──▶ structure ──▶ physics ──▶ analysis
                                  │
                   render ◀───────┴───────▶ ui
```

`physics` and below never import from `render` or `ui`. That keeps the science
testable headlessly and lets the whole engine be driven from a notebook.

| `full_length.py` | **A full-length trimer every analysis can consume.** `FILL_MODES` also carries `trimer`, which is a completeness of the *assembly* rather than of the chain (see `assembly.py`) and shares this selector because it shares what makes the selector worth having: whatever it produces is what every analysis runs on, without any of them knowing. `hybrid.py` grafts onto one protomer and returns coordinates; this returns a real `Structure`, so the dome, the pore, the elastic network, the animations and the measurements all run on it with no further plumbing — which is the point, and the danger. | `hybrid.py` | **The full-length model**: experimental core plus the AlphaFold distal blade, with the seam visible rather than hidden. | `architecture.py` | **Helical elements measured from coordinates** — the cross-helices Figure 7b colours yellow, for which the paper gives no residue range anywhere. | `micelle.py` | **A modelled detergent micelle** — the envelope Figure 4b shows as density, which this project has no map for.
